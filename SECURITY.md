# Security

## What this project is

This repository is a simulated OT/ICS environment for education and security
research. Nothing in this repo — the Modbus slave, the process simulation,
the attacker tooling, the scenario scripts — is intended to be pointed at
real equipment, a real utility, or any network you do not own and control.

**Never run any script in this repository against a target outside the
range's own simulated environment.**

Attack scripts under `attacker/` and `scenarios/` are hard-bound to the
range's own address space and print a scope banner on every run. If a
target is not inside that range, the script refuses to run. Do not
circumvent that guard.

## Responsible use

- Use this range on an isolated machine or isolated virtual network.
- Do not expose any service in this stack (Modbus slave, OpenPLC web UI,
  HMI, historian, Grafana, the M4 router) to
  the public internet. Defaults bind to loopback or an internal Docker
  network only — keep it that way.
- If you adapt scenarios here for a class, CTF, or exercise, keep the same
  scope guards and responsible-use framing for your students/participants.

## Reporting a vulnerability or a sanitization miss

If you find a real secret, a real IP/hostname, a packet capture from a real
network, or anything else that shouldn't be in this repo, please open an
issue or contact the maintainer directly rather than a public PR discussion,
so it can be removed and history scrubbed before wider exposure.

## Sanitization guarantees for this repo

- No real IP addresses, hostnames, ASNs, or topology from any real
  environment. Only documentation-range addresses (RFC 1918 / RFC 5737).
- No packet captures sourced from a real network. Every `.pcap` referenced
  in docs or tests is generated by the range itself.
- Any IOC referenced in documentation is defanged.
- No credentials are ever committed. `.env.example` holds placeholders only;
  real values are generated per-deploy, at runtime, on your own machine.
- Git history is scrubbed of anything that shouldn't be public before the
  repo is ever pushed to a public remote.
- Nothing here is sourced from an employer, a military unit, coursework, or
  a competition — topologies, tooling detail, scenario text, and lessons are
  all independently authored against public CISA/MITRE ATT&CK references.
